## Project Overview

An IoT-enabled modular cableway system designed to transport agricultural produce from remote farms in hilly terrains to collection points. The system utilizes gravity-assisted transportation and solar-powered mechanisms to reduce energy consumption, manual labour and transportation costs.

## Design Motivation

Farmers in hilly regions face difficulties transporting agricultural produce due to uneven terrain, limited road connectivity and high transportation costs. This design provides a sustainable and modular transportation solution by combining mechanical cableway infrastructure with IoT-based monitoring.

## Objectives

- Reduce manual effort in agricultural transportation.
- Enable gravity-assisted downhill transportation.
- Utilize solar energy for powered return movement.
- Monitor cargo weight, location and system health using IoT.
- Develop a modular and scalable transportation system.

## Modelling Methodology

- Rectangular geometries for support bases and towers.
- Cross-braced structures for reinforcement.
- Inclined cylindrical geometry for the cable.
- Circular geometries for pulley wheels and winch mechanisms.
- Hollow rectangular geometry for the cargo pod.
- Coordinate transformations for component positioning and assembly.

## Working Principle

1. Agricultural produce is loaded into the cargo pod.
2. The trolley travels along the inclined cable using gravity-assisted movement.
3. IoT sensors monitor cargo weight, location and transportation conditions.
4. The produce is unloaded at the collection point.
5. A solar-powered winch returns the empty cargo pod uphill.
