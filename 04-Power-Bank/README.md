# Mini Emergency Power Bank

## Overview
A compact and portable 5000 mAh power bank designed for emergency mobile charging using a single rechargeable lithium-ion battery.

## Design Motivation
Conventional power banks can be bulky to carry. This project focuses on a compact, lightweight enclosure that makes emergency charging more convenient.

## Technical Specifications

| Parameter | Specification |
|---|---|
| Battery Type | 21700 Lithium-ion |
| Battery Capacity | 5000 mAh |
| Battery Voltage | 3.7 V |
| Charging Module | Mini USB Type-C Power Bank Module |
| Module Current Rating | 3.1 A |
| Enclosure Material | ABS |
| Manufacturing Method | FDM 3D Printing |
| CAD Software | Autodesk Fusion |

## Material Selection
ABS was selected for its durability, impact resistance, and heat resistance which makes it a suitable candidate for electronic enclosures.

## Working Principle
The lithium-ion battery supplies power to the power bank module, which regulates the output voltage for charging external devices.

## Design Features
- Compact and portable enclosure.
- Single-cell battery configuration.
- USB Type-C connectivity.
- Lightweight and durable housing.
- Designed for emergency charging.

## Project Status
Digital enclosure model completed. Physical fabrication, electrical assembly and charging performance have not been tested.
