# Mechanical CAD Design Experiments - College Work

## Project Overview

A collection of 3D mechanical models developed using Autodesk Fusion 360 as part of college laboratory experiments. The project focuses on mechanical component design, solid modelling and engineering applications.

## Software Used

- Autodesk Fusion 360
